# linux服务器管理

在 Mac 上连接、部署和维护 Linux 服务器。最新正式安装包为 **v0.3.13**，支持 **macOS 11 或更新版本、Intel 与 Apple Silicon**。

GitHub 主分支用于源码更新；正式安装包通过 [GitHub Releases](https://github.com/yushengsheng/linux-manager/releases/latest) 分发。当前主分支另包含本地启动、发布目录和文档整理，业务功能与 v0.3.13 一致。

## 下载独立安装包

1. 从 [最新发布](https://github.com/yushengsheng/linux-manager/releases/latest) 下载 `linux-server-manager-macOS-universal2-v0.3.13.zip`，用同页 `.sha256` 或 `SHA256SUMS` 核验。
2. 正常退出旧程序，解压完整文件夹，将 `linux服务器管理.app` 和 `启动linux服务器管理.app` 保留在一起。
3. 双击 `启动linux服务器管理.app`。安装包自带 Python、Tk 和运行依赖，无需安装开发环境。

更新沿用这台 Mac 原有的服务器档案、项目缓存和钥匙串。新电脑需要自己的连接资料。安装包使用临时签名，未经过 Apple 开发者公证；确认来源及校验值后，如被拦截，按 macOS「隐私与安全性」提示允许打开。

## 本地直接运行最新版源码

已有本地环境时，只需双击根目录 **`启动本地最新版.app`**。更新源码后正常退出旧窗口，再打开同一个入口；运行中的进程不会自动加载修改。日常开发无需生成安装包或带版本号的程序目录。

首次从源码安装时，准备带 Tk 的 Python 3.11 或更新版本，在项目根目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python linux服务器管理.py --desktop-data --self-check
osacompile -o 启动本地最新版.app scripts/启动本地最新版.applescript
```

最后一步只创建轻量启动入口，不复制主程序或运行环境；已有入口时无需重复生成。启动器需要与源码目录放在一起，会优先使用项目虚拟环境，也支持 uv、Homebrew、Python.org 环境。它不打开终端窗口。

也可以在终端直接启动：

```sh
.venv/bin/python linux服务器管理.py --desktop-data
```

`--desktop-data` 继续使用原桌面版档案与钥匙串。源码启动器不能单独复制到其他电脑；分发时使用独立安装包。

## 连接和日常使用

1. 点击左侧「添加新服务器」，填写 SSH 地址、端口、账号和现有密码或私钥。
2. 点击「连接并检查」，首次连接核对服务器身份；勾选「记住登录信息（仅本机）」可保存登录资料。
3. 在「服务器概览」查看状态；「应用管理」包含「安装与配置」和「运行与备份」；账号、安全和操作记录从左侧进入。
4. 执行变更前核对当前服务器与预览内容。任务执行期间不能切换服务器；连接中断后可从操作记录核对原任务结果。

主要功能：

- 保存多台服务器与账号，复用 SSH 连接，通过「管理当前服务器 → 命令行」打开终端。
- 安装与维护小军交易系统、CLIProxyAPI、Hysteria2、独立 VLESS + REALITY、3x-ui 和 Nginx；支持版本选择、配置预览、备份与失败恢复。
- 查看项目状态、访问网址、端口、证书、日志、节点链接和本机生成的二维码。
- 管理 Linux 账号、密码、加密私钥、SSH 登录、防火墙及自动安全更新。
- 将 CLIProxyAPI 配置到本机 GPT / Codex、Claude Code、Pi 或 OpenCode；写入前备份，可恢复原配置。

自动部署支持 Ubuntu 24.04、Debian 12/13；小军交易系统支持 x86_64。云平台安全组仍需按项目端口和协议设置。更多操作见 [完整使用说明](linux服务器管理使用说明.md)。

## 读取其他方式安装的项目

在「应用管理 → 运行与备份」点击 **「刷新读取全部项目」**，读取结果直接合并到项目下拉列表，服务器概览同步显示。

支持 systemd 系统／用户服务、Docker、PM2、独立监听程序和常用安装目录，包括 Hermes。列表和基础信息按服务器保存在本机，重启后恢复；需要最新状态时再次刷新。没有服务记录、未运行且位于非常用目录的项目可手动登记。

程序按部署关系识别公开版本、端口和网页入口。网页通过服务器本机限时 HTTP HEAD 检查及 Nginx 代理关系确认，不读取网页正文、不跟随外部跳转。无法确认时显示原因。

外部服务和容器按已识别能力提供启停、重启，systemd 可管理自启；独立进程和目录只读。无法支持的按钮会禁用。外部项目账号、密码及补充信息只记录在本机钥匙串，实际改密从原项目后台进行。

## 数据与凭据

服务器档案、私钥、项目缓存和操作记录保存在本机；口令使用 macOS 本机非同步钥匙串，不启用云同步或遥测。旧版凭据首次迁移时可能出现多次授权，后续使用集中记录。取消授权后，基础项目信息仍可查看。

部署通过 SSH 向当前所选服务器发送必需的运行配置和公钥，公开软件包由服务器直接从官方来源下载。真实私钥、登录凭据、账号数据、缓存及日志不进入仓库或安装包。配置备份可能含原有凭据，请留在本机。
