# linux服务器管理

在本机通过界面连接、部署和维护 Linux 服务器，当前版本为 **v0.3.11**。独立桌面包适用于 **macOS 11 或更新版本 / Apple Silicon（arm64）**；不含 Intel 或 Windows 桌面包。

## 下载与更新

从 [GitHub Releases](https://github.com/yushengsheng/linux-manager/releases/latest) 下载 `linux-server-manager-macOS-v0.3.11.zip`。解压后，将主程序和无终端启动器放在同一文件夹，双击 `启动linux服务器管理.app`。安装包自带 Python / Tk，无需安装开发环境；可用同页 `SHA256SUMS` 核对完整性。

先正常退出旧程序再打开新版。沿用原本机档案、私钥及钥匙串，不需要重新添加服务器；新版可能需要再次允许访问钥匙串。本包使用临时签名，未经过 Apple 开发者公证：确认下载来源和校验值后，如系统拦截，按 macOS「隐私与安全性」的提示允许打开，不要关闭系统安全检查。

更新说明见 [v0.3.11 发布说明](RELEASE_NOTES.md)。

## 功能

v0.3.11 新增独立 VLESS + REALITY + Vision 部署和 HY2 / VLESS 节点二维码，已通过 [GitHub 全新 Ubuntu 双架构实测](https://github.com/yushengsheng/linux-manager/actions/runs/38336722599)。保留已有 Nginx 与交易系统证书兼容修复；升级管理器不会自动修改服务器。详细验证范围见[测试记录](linux服务器管理测试记录.md)。

- 左侧保存多台服务器与多账号档案；点击即可使用保存的登录信息连接，可用连接直接复用。
- 单机工作区：概览、应用管理、账号、安全与操作记录；全部既有功能保留。
- SSH 持续连接与短暂断线自动重连，执行任务时阻止服务器切换，避免操作错机器。
- 管理当前服务器 → 命令行：复用已有 SSH 连接打开 macOS 系统终端，可连续输入、粘贴多行代码及使用 top、vim；使用当前登录账号，输入 exit 退出。
- 提交前保存固定任务编号，响应丢失先查回执；远端原子去重，新连接有界重试，确认结果可查回，不重跑已完成安全步骤。
- 账号创建、改名、密码和加密密钥管理、登录方式设置及一键安全方案。
- 所有新密码设置入口可一键生成 40 字符强随机密码，新私钥口令为 48 字符；确认密码同步填写。普通账号新密码提交前保存并回读本机钥匙串副本，可从操作记录离线查看。
- 自动安全更新同时核验生效配置和实际 APT 定时调度；不立即补跑升级、不自动重启，失败恢复原配置与定时器状态。
- 小军交易系统、Hysteria2、独立 VLESS + REALITY + Vision、3x-ui 代理面板及 Nginx 的安装、配置调整和版本切换。
- 独立 VLESS 仅填写 TCP 端口，自动生成连接凭据，无需面板、自有域名或证书；与 HY2 可共存。部署后复制单节点链接导入客户端。
- HY2 / VLESS 链接旁提供二维码图标，点击即可扫码导入；二维码只在本机生成。
- 小军交易查询 GitHub API 受限时，自动使用官方公开发行页面和下载链接；无需 GitHub 登录，仍核对具体版本及 SHA-256。
- 部署前显示变化：条件一致无需重复安装，配置变化按需调整，升级降级先备份，失败恢复原项目。
- 服务维护、配置备份恢复、访问网址、端口、节点和订阅信息、运行日志及操作记录。Nginx 核心管理与交易专属入口分离，部署回滚失败可按原任务再次恢复并核验服务状态。
- 项目卸载：移除本程序安装的程序和专属服务，默认保留配置、账号、账本及证书；未知或共享布局拒绝自动卸载。Nginx 仅移除本程序独立站点，不删除共享核心。移除文件保留管理员恢复备份，仍占磁盘。
- 配置页、部署确认及项目信息明确标注 TCP / UDP；HY2 节点仅 UDP，面板节点按实际配置标注 TCP、UDP 或两者，证书验证 TCP 80 单独提示。
- 各功能提供可点击的大白话说明。

登录档案、SSH 私钥、口令及本机管理记录只保存在本机，不启用云同步或遥测。口令保存在 macOS 本机钥匙串。部署只向所选服务器发送运行必需的配置、公钥及公开软件包，私钥不会传到服务器。

详细用法见 [使用说明](linux服务器管理使用说明.md)，验证结果见 [测试记录](linux服务器管理测试记录.md)。自动部署支持 Ubuntu 24.04、Debian 12/13；交易系统支持 x86_64。云平台安全组需自行放行对应端口。

## 本地运行和测试

开发期间直接双击项目根目录的 `启动本地最新版.app`。它使用本机已配置的 Python 3.11 / Tk，直接读取同目录最新源码，无终端窗口；沿用原桌面版档案、加密私钥和本机钥匙串。正常退出旧程序后再打开，修改代码后重启即可，不需要重新打包。先测试，确认稳定后才生成正式安装包。

此入口依赖这台 Mac 的源码目录及运行环境，不能单独分发给其他电脑。独立 `.app` 与 ZIP 留到确认版本没问题后再构建。

使用安装了 Tk 的 Python 3.11 或更新版本（本轮回归使用 Python 3.11 / Tk 9）：

```sh
python3 -m pip install -r requirements.txt
python3 linux服务器管理.py --desktop-data
python3 tools/run_tests.py
```

非 macOS 环境不提供本机钥匙串保存功能。真实服务器测试工具需要使用者自行准备本机测试档案，不会从仓库获取任何登录资料。

## 构建 macOS 程序

```sh
python3 tools/build_desktop.py
```

构建工具使用隔离环境及固定的打包依赖，输出到 `/private/tmp/linux-manager-build/dist/`。生成的 `linux服务器管理.app` 可直接双击打开；原生程序元数据同步源码版本，构建后重新签名并核验。本次公开包仅在 macOS / arm64 构建与验收。

如需同文件夹的无终端启动器，在 macOS 中执行：

```sh
osacompile -o 启动linux服务器管理.app scripts/启动linux服务器管理.applescript
```

把启动器与主程序放在同一文件夹。仓库不包含本机登录资料、私钥、运行数据或历史安装包。
