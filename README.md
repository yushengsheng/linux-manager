# linux服务器管理

在本机通过界面连接、部署和维护 Linux 服务器，当前版本为 **v0.3.4**。桌面版适用于 macOS。

## 功能

- 多服务器、多账号登录档案；SSH 持续连接与短暂断线自动重连。
- 账号创建、改名、密码和加密密钥管理、登录方式设置及一键安全方案。
- 小军交易系统、Hysteria2、3x-ui 代理面板及 Nginx 的安装、配置调整和版本切换。
- 部署前显示变化：条件一致无需重复安装，配置变化按需调整，升级降级先备份，失败恢复原项目。
- 服务维护、配置备份恢复、访问网址、端口、节点和订阅信息、运行日志及操作记录。
- 各功能提供可点击的大白话说明。

登录档案、SSH 私钥、口令及本机管理记录只保存在本机，不启用云同步或遥测。口令保存在 macOS 本机钥匙串。部署只向所选服务器发送运行必需的配置、公钥及公开软件包，私钥不会传到服务器。

详细用法见 [使用说明](linux服务器管理使用说明.md)，验证结果见 [测试记录](linux服务器管理测试记录.md)。自动部署支持 Ubuntu 24.04、Debian 12/13；交易系统支持 x86_64。云平台安全组需自行放行对应端口。

## 本地运行和测试

使用安装了 Tk 的 Python 3.13：

```sh
python3 linux服务器管理.py
python3 tools/run_tests.py
```

非 macOS 环境不提供本机钥匙串保存功能。真实服务器测试工具需要使用者自行准备本机测试档案，不会从仓库获取任何登录资料。

## 构建 macOS 程序

```sh
python3 tools/build_desktop.py
```

构建工具使用隔离环境及固定的打包依赖，输出到 `/private/tmp/linux-manager-build/dist/`。生成的 `linux服务器管理.app` 可直接双击打开。

如需同文件夹的无终端启动器，在 macOS 中执行：

```sh
osacompile -o 启动linux服务器管理.app scripts/启动linux服务器管理.applescript
```

把启动器与主程序放在同一文件夹。仓库不包含本机登录资料、私钥、运行数据或历史安装包。
